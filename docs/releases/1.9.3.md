# DieCut Catalog 1.9.3

Версия 1.9.3 объединяет исправления, подготовленные после 1.9.1, и усиливает целостность данных, контроль доступа, аудит и безопасность технических PDF. Промежуточная версия 1.9.2 публично не выпускалась.

## Обновление учётных записей

- PostgreSQL data migration заменяет сохранённую строковую роль `Employee` на `Operator`;
- записи `Administrator` не изменяются;
- upgrade integration test воспроизводит обновление production-базы, чтение старой учётной записи и вход по паролю.

## Справочники и переносы

- Copy, Move и Duplicate сохраняют технологическую статью `ArticleRtf` и допустимое архивное состояние;
- Move выполняется сервером атомарно в одной PostgreSQL-транзакции, включая создание назначения, удаление источника и аудит;
- клиент больше не выполняет псевдотранзакцию из нескольких сетевых запросов;
- архивный пользовательский справочник доступен только для чтения на уровне API;
- сервер блокирует изменение значений и статей, CSV-импорт, Copy в архив и Move из архива;
- отклонённая операция не оставляет частичных данных или ложного события аудита.

## Excel-импорт

- удалённые ножи не участвуют в сопоставлении импортируемых строк;
- законная пара `Deleted + Active` с одинаковым оборудованием и номером больше не вызывает duplicate-key exception;
- импорт обновляет действующую запись.

## RBAC и Danger Zone

- закреплена классическая двухролевая модель «оператор / администратор»;
- опасное действие может инициировать только текущий администратор;
- подтверждение принимается только по собственному паролю этого администратора;
- оператор не получает права через пароль другого пользователя;
- журнал сохраняет фактического инициатора операции.

## Универсальный аудит

- добавлен `AuditEvent` с actor, необязательным approver, объектом, действием, JSON-снимками до/после и correlation ID;
- журналируются изменения групп, справочников, значений, статей, CSV-импорт, Copy и Move;
- события доступны в общем журнале и экспорте CSV/PDF;
- накопленная история Copy/Move переносится миграцией.

## Безопасная генерация PDF

- специальная форма, перфорация и неизвестные фигуры больше не рисуются ложным прямоугольником;
- параметрическая генерация разрешена для прямоугольника, корректного квадрата и круга;
- круг и квадрат требуют равенства размеров L и B;
- для произвольного контура требуется загрузить утверждённый PDF;
- отклонённая генерация не создаёт файл, документ или событие «PDF сформирован».

## Установка

Сервер при запуске автоматически применяет миграции. Перед production-обновлением создайте резервную копию PostgreSQL. Windows-клиент получает пакет 1.9.3 через встроенную проверку обновлений, проверяет размер и SHA-256, устанавливает его отдельным updater и перезапускается.
