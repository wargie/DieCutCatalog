# DieCut Catalog 1.9.4

Версия 1.9.4 устраняет расхождение производственного ресурса: часть карточек сохраняла порог 1 000 000 оборотов, а часть — 500 000.

## Что изменилось

- для всех ножей установлен единый ресурс до проверки **500 000 оборотов**;
- текущий тираж, пробег в метрах и количество оборотов обнуляются;
- пожизненный тираж, пробег и обороты сохраняются;
- статусы ножей и журнал событий не изменяются;
- новые ножи по-прежнему создаются с порогом 500 000 оборотов;
- при достижении порога нож автоматически получает статус **Требует проверки**.

## Причина исправления

Ранее подготовленный файл `SetInspectionIntervalTo500000` не имел метаданных EF Core migration и не попадал в список применяемых миграций. Версия 1.9.4 содержит зарегистрированную migration `20260821100000_NormalizeInspectionResourceTo500000`, которую сервер автоматически применяет при запуске.

## Проверка обновления

PostgreSQL upgrade integration test создаёт базу в состоянии 1.9.3, сохраняет ножи с порогами 1 000 000 и 500 000, применяет миграцию 1.9.4 и проверяет:

- одинаковый новый порог 500 000;
- нулевые текущие счётчики;
- сохранённые пожизненные показатели;
- неизменные статусы.

## Установка

Перед обновлением production-сервера создайте резервную копию PostgreSQL. После запуска API миграция применяется автоматически. Windows-клиент получает версию 1.9.4 через **Check updates**, проверяет размер и SHA-256 пакета, устанавливает обновление отдельным updater и перезапускается.
