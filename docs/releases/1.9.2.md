# DieCut Catalog 1.9.2 — не публиковалась

Версия 1.9.2 была промежуточной и не публиковалась в GitHub Releases. Исправления и обязательная миграция вошли в проверенный публичный выпуск [1.9.3](1.9.3.md).

## Причина

Роль сотрудника хранится в PostgreSQL строкой. Поэтому сохранённое значение `Employee` нельзя преобразовать в новый enum только за счёт сохранения числового значения `0`.

## Исправление

- data migration заменяет `employees."Role" = 'Employee'` на `Operator`;
- обратная миграция восстанавливает значение `Employee`;
- записи `Administrator` не изменяются;
- добавлен PostgreSQL upgrade integration test с реальной цепочкой миграций, чтением сотрудника и входом по паролю.

## Обновление

Не устанавливайте промежуточную сборку 1.9.2. Обновляйте сервер и Windows-клиенты сразу до 1.9.3.
