# DieCut Catalog 1.9.0

Версия 1.9.0 завершает новый рабочий сценарий раздела **Справочники**: группы, CSV-импорт, карточки-статьи и операции над значениями теперь доступны непосредственно в Windows-клиенте.

![Раздел справочников](../images/references.png)

## Главное

- раскрываемые группы пользовательских справочников, включая пустые группы;
- импорт значений из CSV с пропуском пустых строк и дублей;
- просмотр и форматированное редактирование статьи для каждого значения;
- контекстные команды просмотра, редактирования, удаления, дублирования, копирования и переноса;
- удаление пустой пользовательской группы через **Danger Zone** с паролем администратора;
- исправления входа, серверных маршрутов, контраста, отступов, стандартного управления окном и выпадающего списка стилей.

![Редактор карточки позиции](../images/reference-article-editor.png)

## Данные и совместимость

Миграция `AddReferenceValueArticles` добавляет хранение форматированных статей. В production 43 карточки с материалом `Clear` переведены на `Clear PET30`, после чего устаревшее значение удалено из системного справочника.

Клиент 1.9.0 требует обновлённый API 1.9.0 для сохранения статей и удаления групп.
