# Вопросы по интеграции с API JustCut

Здравствуйте!

Мы планируем интегрировать API JustCut с нашим внутренним приложением — каталогом вырубных ножей. Нам известно, что API возвращает окончательную стоимость с НДС. Для подготовки интеграции просим уточнить следующие вопросы.

## 1. Доступ к API

1. Нужна ли дополнительная авторизация: логин, пароль, API-ключ или сертификат?
2. Какие полные URL необходимо использовать для методов `ping` и `requestpriceknife`?
3. Требуется ли добавить IP-адрес нашего сервера в белый список?
4. Доступен ли API по HTTPS? В инструкции указан HTTP и порт `8081`.
5. Отличаются ли `uidcontragent` для тестовой и рабочей сред?

## 2. Расчёт стоимости

6. Возвращается ли детализация стоимости или только итоговая сумма?

## 3. Технические параметры ножа

   - `width`;

## 5. Создание заказа и синхронизация номера JC

26. Доступен ли сейчас режим `typeorder = 1` для создания реального заказа?

28. Какое из этих значений является номером заказа, который видит клиент?

32. Какой параметр следует использовать для последующего поиска и синхронизации заказа?
33. Можно ли запросить актуальное состояние заказа по его номеру или UID?
34. Есть ли отдельный метод получения информации о заказе?

39. Работает ли повтор заказа через `numberrepeatorder`?
40. Когда создание и повтор заказов будут доступны в рабочей среде?

Для нас особенно важна автоматическая синхронизация номера заказа. Поле «Номер заказа JC» уже присутствует в нашем приложении, но сейчас заполняется вручную. После создания заказа через API мы хотим автоматически записывать полученный номер в карточку соответствующего ножа.

Просим подтвердить рекомендуемое соответствие:

```text
JustCut numberorder → наше поле «Номер заказа JC»
```

Также просим уточнить, возможно ли синхронизировать номера уже существующих заказов.
