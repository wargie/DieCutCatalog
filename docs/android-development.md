# Android-клиент DieCut Catalog

Android-приложение находится в `src/DieCutCatalog.Mobile` и собирается отдельным решением `DieCutCatalog.Mobile.sln`. Оно использует тот же production API, учётные записи и центральную PostgreSQL-базу, что и Windows-клиент. Локальной копии каталога на телефоне нет: изменения тиража сразу записываются сервером и видны на всех ПК и мобильных устройствах.

Текущая версия: **0.3.0**. Начиная с неё приложение получает подписанные обновления через рабочий сервер. Первый переход с 0.2.0 выполняется вручную из-за замены тестового сертификата постоянным ключом FLEXPRINT.

![Карточка ножа в Android](images/android-knife-card.png)

## Разделение функций

**Windows-клиент** предназначен для полного ведения каталога: создания и редактирования ножей, импорта Excel/PDF, генерации чертежей, справочников, сотрудников, журналов и административных операций.

**Android-клиент** предназначен для работы у оборудования:

- вход под общей учётной записью сотрудника;
- просмотр актуального каталога и карточек ножей;
- поиск и фильтрация по тем же группам оборудования;
- компактный и подробный вид списка;
- ввод тиража в штуках или пробега в метрах;
- серверный пересчёт тиража, пробега и целых оборотов;
- просмотр и редактирование личного профиля с подтверждением паролем.

Операции создания, удаления, списания и редактирования геометрии ножа в мобильный клиент намеренно не включены.

## Worktree и ветки

- `main` — источник истины для API, Windows и Android;
- `codex/android-bootstrap` — текущая функциональная ветка Android;
- отдельный worktree `DieCutCatalog-Android` позволяет собирать мобильный клиент независимо от работы над ПК-версией.

Перед объединением Android-ветка обновляется из `main`, полностью собирается и проверяется на реальном сервере. После проверки изменения вливаются в `main` коротким pull request.

## Требования для сборки

- Windows 10/11 x64;
- .NET SDK 9;
- workload `maui-android`;
- Microsoft OpenJDK 17;
- Android SDK API 35;
- устройство Android 10 (API 29) или новее.

Проверка окружения:

```powershell
dotnet --info
dotnet workload list
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" version
```

При отсутствии workload:

```powershell
dotnet workload install maui-android
```

## Сборка APK

Основная команда из Android-worktree:

```powershell
.\scripts\Build-AndroidRelease.ps1
```

Android `aapt2` не работает с кириллицей в полном пути проекта. Скрипт автоматически подключает worktree временной буквой диска. Ручной эквивалент:

```powershell
subst R: "D:\Вырубка\Rotazija\Каталог ножей\DieCutCatalog-Android"
Set-Location R:\
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-17.0.20.8-hotspot"
dotnet build DieCutCatalog.Mobile.sln -c Release --no-restore
Set-Location C:\
subst R: /d
```

Подписанный APK появляется в:

```text
src\DieCutCatalog.Mobile\bin\Release\net9.0-android\com.flexprint.diecutcatalog-Signed.apk
```

Перед новым релизом увеличьте `ApplicationDisplayVersion` и `ApplicationVersion` в `DieCutCatalog.Mobile.csproj`.

## Установка на телефон

### Из GitHub Release

1. Откройте на телефоне страницу [Android 0.2.0](https://github.com/wargie/DieCutCatalog/releases/tag/android-v0.2.0).
2. Скачайте `DieCutCatalog-Android-0.2.0.apk`.
3. Разрешите установку приложений из этого источника, если Android запросит разрешение.
4. Откройте APK и нажмите **Установить**.
5. После обновления запускайте приложение обычным ярлыком. Данные каталога не удаляются, поскольку они хранятся на сервере.

### Через USB для разработки

1. Включите на телефоне режим разработчика и **Отладку по USB**.
2. В настройках USB выберите **Передача файлов/Android Auto**.
3. Подтвердите доверие к компьютеру на телефоне.
4. Выполните:

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb devices
& $adb install -r "src\DieCutCatalog.Mobile\bin\Release\net9.0-android\com.flexprint.diecutcatalog-Signed.apk"
```

Статус устройства должен быть `device`, а не `unauthorized`.

## Подключение и работа

Production-адрес встроен в приложение: `https://diecutcatalog.duckdns.org`.

1. Проверьте в браузере телефона адрес [https://diecutcatalog.duckdns.org/health](https://diecutcatalog.duckdns.org/health). Ответ должен быть `Healthy`.
2. Войдите с той же электронной почтой и паролем, что в Windows-клиенте.
3. Если сервер требует сменить временный пароль, сначала выполните смену в Windows-клиенте.
4. Выберите оборудование или найдите нож по номеру.
5. Откройте карточку и нажмите **Добавить тираж**.
6. Выберите режим **Тираж** или **Пробег**, введите одно значение и проверьте предварительный расчёт.
7. Подтвердите операцию. Окончательный расчёт и запись выполняет сервер.

## Выпуск версии

Рекомендуемая схема тегов не пересекается с Windows-релизами:

- ПК и сервер: `v1.0.2`, `v1.1.0`;
- Android: `android-v0.2.0`, `android-v0.2.1`.

Android-релиз до завершения пилотной эксплуатации публикуется как prerelease. В релиз прикладывается только подписанный APK и краткое описание изменений.

## Диагностика

- **Не подключается:** откройте `/health`, проверьте интернет, дату и время телефона.
- **401:** неверная почта или пароль; войдите повторно.
- **428 / требуется смена пароля:** смените временный пароль в Windows-клиенте.
- **Приложение не устанавливается поверх старого:** APK подписаны разными ключами; удаление старой тестовой сборки удалит только локальные настройки, но не серверные данные.
- **Телефон не виден через ADB:** переключите USB на передачу файлов, переподключите кабель и подтвердите RSA-ключ.
- **Сборка выдаёт APT2000:** запускайте её через `scripts\build-android.ps1` или временный диск без кириллицы в пути.

## Обновление через сервер

После входа приложение один раз проверяет `GET /api/updates/android/latest`. Ручная проверка доступна в личном профиле. При наличии новой версии пользователь видит номер, размер и описание выпуска. APK скачивается с рабочего HTTPS-сервера, проверяется по размеру и SHA-256, после чего открывается штатный установщик Android.

При первом обновлении Android попросит разрешить установку из приложения DieCut Catalog. Это разрешение относится только к этому источнику. Сервер хранит Android-публикацию отдельно от Windows в `updates/android`.

Публикация готового подписанного APK:

```powershell
./scripts/Publish-AndroidUpdate.ps1 `
  -Version 0.3.0 `
  -VersionCode 4 `
  -ApkPath ./artifacts/android/DieCutCatalog-Android-0.3.0.apk `
  -ReleaseName "DieCut Catalog Android 0.3.0" `
  -Notes "Обновления Android через рабочий сервер"
```

Файл `C:\Users\<пользователь>\.diecutcatalog\android-signing.json` и keystore не входят в Git. Их резервная копия обязательна: без исходного ключа Android не позволит выпускать обновления поверх установленного приложения.
